## Projet principal

### [SunsetEngine](https://github.com/SunvyWasTaken/SunsetEngine)

**SunsetEngine** est un moteur de jeu C++23 modulaire conçu pour fournir une base complète à des applications et jeux temps réel.

Le moteur comprend notamment :

* Architecture applicative avec boucle principale et système de `Layer`
* Game Framework basé sur **EnTT ECS**
* Rendu **OpenGL**
* Gestion des shaders, matériaux, textures, meshes et buffers
* Framebuffers et pipeline de rendu
* Systèmes de caméra et de drawables
* Système d'entrées configurable
* Networking basé sur **ENet**
* Mode **headless** pour les applications serveur et simulations
* Système audio basé sur **OpenAL**
* UI retained-mode avec **SRmGUI**
* Sérialisation et sauvegarde binaire
* Système de réflexion runtime
* Logging et profiling
* Outils de debug
* Prototype d'éditeur intégré au moteur

L'architecture est pensée pour garder les différents modules indépendants. Le cœur du moteur ne dépend notamment pas directement de GLFW ou d'OpenGL, ce qui permet d'envisager différents backends et implémentations de plateforme.

## Autres projets

### SunsetCraft

**SunsetCraft** est un projet de jeu voxel inspiré de Minecraft développé pour mettre à l'épreuve les systèmes de SunsetEngine.

Le projet explore notamment :

* Génération procédurale de terrain
* Voxel rendering
* Chunk system
* Texture atlases
* Frustum culling
* Gestion des biomes
* Systèmes de sauvegarde
* Réseau multijoueur
* Architecture ECS

SunsetCraft sert également de projet concret pour développer et tester les fonctionnalités du moteur dans une application réelle.
